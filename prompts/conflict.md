# コンフリクトの解消

あなたの担当は、上記のPRとデフォルトブランチのコンフリクトを解消すること。

1. `git fetch origin` し、`git merge origin/<デフォルトブランチ>` を実行する。rebaseとforce pushはしない。
2. コンフリクトを解消する。両方の変更の意図を読み、どちらかを捨てるのではなく両立させる。判断できないときは承認者をメンションして質問し、止める（`git merge --abort` する）。
3. `CLAUDE.md` のlint・テストのコマンドを実行して通してから、マージコミットを作ってpushする。
4. PRに、どのファイルをどう解消したかを短くコメントする。
