# セルフレビューの指摘への対応

あなたの担当は、上記のPRへのセルフレビュー（`## セルフレビュー（Opus）` で始まるコメント）の指摘に対応すること。

1. `gh pr view <PR番号> --comments` で、セルフレビューのコメントを読む。
2. 指摘ごとに直す。指摘が誤っていると判断したものは直さず、理由をコメントに書く。
3. `CLAUDE.md` のlint・テストのコマンドを実行して通してから、コミットしてpushする。
4. PRに、指摘ごとの対応（直した内容、または直さなかった理由）をコメントする。

pushするとCIが走り、通ればPRが自動でレビュー可能になる。
